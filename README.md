# 배우 박지오 — 프로필 사이트

공개 주소: **https://actor-park.github.io/**

소개 랜딩 페이지 · 디지털 명함 · 포트폴리오를 한 페이지에 담고,
QR 유입을 포함한 방문 통계를 따로 볼 수 있는 정적 사이트입니다.

```
actor-park.github.io/   (저장소 루트)
├─ index.html          랜딩 · 명함 · 포트폴리오
├─ admin.html          방문 분석 콘솔 (로그인)
├─ assets/
│  ├─ portrait-*.jpg   프로필 사진 3종
│  ├─ still-*.jpg      작품 스틸 9종 (자막 라벨 제거 · 16:9 정규화)
│  ├─ qr-naver.png     네이버 인물정보 QR (원본 PDF에서 추출)
│  ├─ parkjioh-profile.pdf   원본 프로필 PDF (내려받기용)
│  ├─ collector.gs     방문 수집용 Google Apps Script (선택)
│  └─ js/
│     ├─ qr.js         QR 인코더 (외부 라이브러리 없음)
│     ├─ analytics.js  방문 기록
│     └─ config.js     수집 서버 주소 설정
└─ README.md
```

## 페이지

**랜딩 (`index.html`)** — 히어로, 프로필, 출연작 26편(분류 필터), 작품 스틸
9컷(라이트박스), 디지털 명함. 명함에서 연락처(vCard) 저장, 프로필 PDF 내려받기,
공유, 인쇄(A4 한 장 이력서 레이아웃)를 지원합니다.

**랜딩 QR** — 명함 영역의 QR은 **페이지가 열린 실제 주소**로 그때그때 생성됩니다.
도메인을 바꿔도 다시 만들 필요가 없습니다. 인쇄용 PNG·SVG로 내려받을 수 있고,
QR 주소에는 `?src=qr`가 붙어 있어 **QR로 들어온 방문이 통계에서 따로 잡힙니다.**

**관리자 (`admin.html`)** — 누적 방문 요약(KPI 5종), 자동 생성 문장 요약,
일별 방문 추이, 유입 경로, 시간대별 방문, 기기·브라우저, 최근 방문 로그,
기간 필터(7·30·90일·전체), CSV 내보내기.
실제 기록이 없어도 **「샘플」** 버튼으로 화면을 미리 볼 수 있습니다.

## 방문 통계를 모든 방문자 기준으로 모으려면

정적 페이지에는 서버가 없으므로 **기본값은 방문자 각자의 브라우저에만 기록**됩니다.
즉 관리자 페이지에서는 내 기기의 기록만 보입니다. 전체 방문자를 합산하려면
무료로 쓸 수 있는 수집기를 한 번 연결하면 됩니다.

1. 구글 시트를 하나 만들고, **그 시트 안에서** 확장 프로그램 → Apps Script를 엽니다.
   `assets/collector.gs` 내용을 그대로 붙여넣습니다.
   (시트 안에서 열면 스크립트가 그 시트에 연결되므로 **시트 ID를 복사할 필요가 없습니다.**)
2. 운영 Apps Script의 `WRITE_TOKEN`과 관리자 전용 `READ_KEY`를 구분합니다.
   `READ_KEY`는 공개 저장소에 넣지 않습니다. 공개 `assets/collector.gs`는 비밀을 제외한 사본입니다.
3. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: 모든 사용자 → `/exec` 주소 복사.
4. `assets/js/config.js`에 그 주소와 **공개 WRITE_TOKEN만** 넣고 커밋합니다.

```js
window.PJA_CONFIG = {
  endpoint: 'https://script.google.com/macros/s/.../exec',
  token: '여기에_같은_토큰'
};
```

연결하면 관리자 페이지 상단 배너가 「수집 서버 연결됨」으로 바뀌고, 모든 방문이 합산됩니다.

## 알아 두실 점

- 관리자 비밀번호는 Apps Script 서버가 POST 요청으로 확인합니다. 방문 기록 조회에도
  인증이 필요하며 공개 전송 토큰은 조회 권한이 없습니다. GET 인증은 받지 않습니다.
- 관리자 비밀번호는 현재 페이지 메모리에만 보관합니다. 과거 버전이 저장한 비밀번호는
  관리자 페이지를 열 때 제거합니다. 새로고침·재접속하면 다시 로그인해야 합니다.
- 5분 내 비밀번호 인증이 8회 실패하면 관리자 인증을 60초 제한합니다. 이 수집기는
  신뢰할 수 있는 방문자 IP를 제공받지 못하므로 제한은 관리자 전체에 공통 적용됩니다.
  잠금 중 요청으로 시간이 연장되지는 않습니다. 다중 인증이나 공격 방어 서비스는 아닙니다.
- 방문 데이터는 입력 크기·허용 값·숫자 범위를 제한하고 시트 수식 시작 문자를 무효화합니다.
  CSV 다운로드도 수식 시작 문자를 무효화하고 필드를 인용합니다. Google 시트의 기존
  수식이나 과거 CSV 파일은 이 배포로 변경되지 않습니다.
- 방문 기록에는 IP나 개인 식별 정보를 남기지 않습니다. 기기 종류, 브라우저,
  유입 경로, 시각, 브라우저별 임의 ID만 저장합니다.
- 작품 스틸의 저작권은 각 제작사에 있습니다.

## 로컬에서 보기

운영 통계를 오염시키지 않도록 수집 서버 연결을 제거한 안전한 미리보기를 사용합니다.
이 작업 환경의 실행 방법은 저장소 밖의 로컬 `START_HERE.md`를 참고합니다.
수집 서버가 없는 미리보기에서는 관리자 인증을 허용하지 않습니다.
